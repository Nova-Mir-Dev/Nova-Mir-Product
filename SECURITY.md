# Security Policy

## Reporting a Vulnerability

Please report security issues to **hello@novamir.dev**. We will respond within 48 hours.

Do not file public issues for security vulnerabilities.

## Supported Versions

We only support the latest deployment on `main`. No backports are provided.

## Disclosure

We will acknowledge receipt within 2 business days and provide an estimated fix timeline. Once a fix is deployed, we disclose the issue after users have had reasonable time to update.
